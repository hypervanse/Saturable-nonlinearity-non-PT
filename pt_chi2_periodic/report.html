Moreira, Konotop & Malomed · Phys. Rev. A 87, 013832 (2013)

Gap solitons in a PT-symmetric χ(2) lattice

The thesis algorithms, run end to end. Edge shooting with an adaptive RKF4(5) integrator follows the Fig. 3.1 flowchart; a cubic spline carries the result into Newton–Raphson on a symmetric central-difference grid; then come continuation in α and b, linear stability, and split-step Fourier propagation. Everything is written in plain numpy.

Pipeline

  1. Floquet spectrum. Monodromy over one period gives band edges, gaps and the decaying tail (w, w′) = C(1, r) at ξf = nπ.
  2. Edge shooting at α = 0. RKF4(5) integrates inward from ξf to 0. A step is rejected and refined when max|y5 − y4| exceeds tolerance. The SH tail adds the Floquet particular solution forced by w1². The nested flowchart finds C2 with w2′(0) = 0, then C1 with w1′(0) = 0, and a 2-D Newton step polishes the last digits. Inward integration is stable because the unwanted Floquet solution decays on the way in.
  3. Cubic spline. A clamped spline maps the adaptive RK mesh onto the uniform grid, with the end slopes taken from the RK state.
  4. Newton–Raphson. The unknowns live on the half grid. Ghost points use the mirror rule (Re w even, Im w odd), which is the central-difference form of the PT symmetry and removes the phase zero mode. The box is periodic with L a multiple of π/2, because Dirichlet walls break the PT symmetry of a finite lattice.
  5. Continuation switches on α, then follows each branch in b with a secant predictor.
  6. Linear stability uses the paper's Eq. (14) on the same grid and the same d² matrix as Newton. A complex absorbing layer pushes box modes to Im λ < 0, so the growth rate is max Im λ.
  7. Split-step Fourier (Strang or Yoshida-4) has exact dispersion and an RK4 χ(2) substep. Its initial state is the Newton solution on the same grid, plus 10% noise.

Where the results differ from the paper

Third finite gap, α = 0. The branch the paper draws as stable (Fig. 5) has an oscillatory instability, with growth up to 0.038 for b between −1.25 and −1.15. An absorbing layer of any strength gives the same rate, and direct propagation confirms it: the deviation grows at 0.028 against Im λ = 0.028 at b = −1.197. The unstable eigenvector keeps an oscillating tail. That fits an internal mode resonating with the opposite-signature continuum, which overlaps in finite gaps.

Weak instabilities below the paper's resolution. Two points the paper calls stable have small growth rates that converge in box size: case 3 at b = 0.21 (Im λ = 3.6e-03) and the third gap at α = 0.7919, b = −1.207 (Im λ = 1.0e-03). Over ζ = 1000 that amounts to e3.6 and e1.0, which is hard to see in noisy propagation or on eigenvalue axes of ±0.1.

Typos in the paper. Eq. (9) has q with the opposite sign to Eq. (10); the numbers follow Eq. (10). The third-gap matching value is printed as 1.29 but is −1.29. The "P = 0.5" captions are rounded: the dots sit at P ≈ 0.45–0.47.

Lattice centring. In the third gap the fundamental soliton sits on the potential minimum, ξ0 = π/2, because the FF band-edge Bloch mode is odd about ξ = 0. Shooting about ξ = 0 only finds multi-hump states there.

Reproduce it

The zip bundle holds the code, the computed results, these figures and REPRODUCE.md, a step-by-step guide with the output each step should print and fixes for the usual failures. Only numpy is needed. The results folder is included, so the last two commands alone rebuild every figure and this page.

python3 validate.py        # building-block checks              (~5 min)
python3 run_bands.py       # Floquet band edges                  (~2 min)
python3 run_semiinf.py     # semi-infinite gap, cases 1-3        (~35 min)
python3 run_thirdgap.py    # third finite gap                    (~45 min)
python3 validate_weak.py   # weak instabilities by propagation   (~15 min)
python3 make_figures.py    # SVG figures (+PNG if Chromium exists)
python3 build_report.py    # this page
